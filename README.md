# CodePOS MX — Mini sitio para NFC

Página ligera para tarjetas y etiquetas NFC. No requiere compilación ni dependencias.

## Probar en local

Desde la raíz ejecuta `python3 -m http.server 8000` y abre <http://localhost:8000/link.html>.

## Publicar con GitHub Pages

En **Settings → Pages**, selecciona `main` y la carpeta `/ (root)`. Después de que Pages confirme el despliegue, verifica esta URL HTTPS antes de grabarla en una etiqueta NFC:

https://chemazu22.github.io/CodePOSMX-link-nfc/link.html
